# Resume Kitchen 简历厨房

每个人独立部署、独立保管资料的中英文简历工具。先保存完整经历，再按求职方向选取，生成可继续编辑的 Word。面向法学生设计，也可用于其他专业。

## 已实现

- 空白资料库启动，无内置私人简历或照片。
- 个人姓名、英文姓名、联系方式和可选照片。
- 教育、实习、实践、科研、荣誉技能、兴趣的新增和编辑。
- 一次批量导入最多 30 份 PDF、DOCX、UTF-8 TXT 或 Markdown；在本机按栏目、标题和日期拆分经历，合并重复条目并提示日期冲突。
- 原始长文、来源文件列表与最终简历表述分开保存，便于追溯和复核。
- 自定义投递方向，分别保存经历组合；同一经历可用于多个方向。
- 中文、英文、双语可编辑 DOCX；深蓝标题、细红线、逐条自适应的无边框表格自动对齐。日期栏按实际长度取宽，长标题只调整本条字号，末尾短职位词组保持完整。
- 概括标签单下划线，标题加粗，英文职位斜体。
- 修改中文后提示核对英文，不以过期英文冒充同步完成。
- 独立生成记录、内容快照、经历编辑历史，不覆盖旧 Word。
- 可选 LibreOffice 实际渲染，有限范围内调整行距、段距和字号，使每种语言尽量一页并平衡上下留白。
- 附带详细的法学生简历 Skill：[`skills/legal-resume-studio/SKILL.md`](skills/legal-resume-studio/SKILL.md)。

## 重要范围

这是**每人一个实例**的工具，不是供陌生人注册的多租户网站。当前不包含登录、权限隔离、公网 HTTPS 或账号找回。默认仅发布到本机回环地址，不能直接改为公网开放。远程使用可通过受控 SSH 隧道访问自己的实例；公开服务须另行实现认证与安全部署。

GitHub 托管源码；GitHub Pages 不能运行此 Python 后端。资料放在部署者的数据目录／Docker 卷，不会自动提交 Git，也不上传给项目作者。

未接入自动 AI 提炼／翻译。网页提供选句、编辑和复制加工请求；需要 AI 时可把请求交给自己的 AI 工具，再将确认结果填回。项目不提供免费 GPT 额度，不自动调用外部服务。

不能保证任意内容量都恰好占满一页，也不保证 LibreOffice 与 Mac WPS 的换行完全一致。自动适配不修改措辞，正文不低于 9.5 磅。达到阈值仍排不下、内容过少或渲染失败，会提示而不是宣称通过。自动版面检查不等于逐条事实、法律术语和孤字的人工精校。

## 本机运行

需要 Python 3.10 或以上。在项目目录执行：

```sh
python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows PowerShell 使用 .venv\Scripts\Activate.ps1
pip install -r requirements.txt
python server.py
```

打开 http://127.0.0.1:8765 。先点击“个人信息与照片”，再新增经历和投递方向。

生成基本 Word 不要求安装 LibreOffice。自动适配还需要 `soffice` / `libreoffice` 可执行程序，可通过 `SOFFICE_PATH` 指定其路径。推荐安装 Noto Serif CJK SC 与 Liberation Serif；字体缺失时目标软件可能替换字体，须重新检查排版。项目不分发商业字体。

配置环境变量：

| 变量 | 默认值 | 用途 |
|---|---|---|
| `PORT` | `8765` | 本机端口 |
| `BIND_HOST` | `127.0.0.1` | 监听地址；不要直接对公网开放 |
| `RESUME_DATA_DIR` | 项目内 `data` | 资料、历史及生成文件位置 |
| `SOFFICE_PATH` | 从 PATH 查找 | LibreOffice 路径 |

## Docker 部署

已安装并启动 Docker Engine / Docker Desktop 和 Compose 的用户可以运行：

```sh
docker compose up --build -d
```

打开 http://127.0.0.1:8765 。如果已有程序占用该端口，可修改 Compose 中左侧主机端口，并使用对应地址；跨端口的来源检查须同时配置，当前建议保持端口一致。

容器以非 root 用户运行，安装 LibreOffice 和开源字体；资料保存在 `resume-data` 持久卷。`docker compose down` 不删除该卷，`docker compose down -v` 会删除数据，请勿用于日常停止。

本地源码运行已测试。Docker 配置的实际构建验证状态见下方“验证记录”；未验证的平台不能视为已经支持通过。部署机器、Docker 产品和任何外部 AI 服务可能有各自费用或许可条件，项目不承诺第三方服务免费。

## 使用与保存

1. 填个人信息；照片可选。
2. 点击“批量导入旧简历”，可一次选择多份文件。系统会自动拆分和去重；复杂文本框、扫描件、无日期标题或特殊版式可能无法准确识别，必须查看“待核对”标记。扫描版 PDF 暂不提供 OCR。
3. 也可逐条新增经历，上传或粘贴完整材料，填写简历表述。批量导入不会补造缺失事实，也不会自动生成英文。
4. 需要英文时填写英文机构／职位、日期及表述，并核对事实。
5. 新建方向、按希望的顺序勾选条目；生成时按栏目分组，同栏目保留勾选顺序。
6. 生成并阅读排版结果，下载 Word 后在投递软件检查。
7. 下一次可继续编辑；历史文件和快照保留。

`data/state.json` 保存个人资料、经历、方向和历史；`data/generated/` 保存 Word；`data/layout-checks/` 保存版面检查图。备份时停止程序后复制整个数据目录（Docker 用户备份持久卷）。只备份源码不等于备份简历。

不要将数据目录、照片、截图、Word、环境配置或 API 密钥加入公开仓库。发布前检查暂存区，而不是仅依赖 `.gitignore`。
